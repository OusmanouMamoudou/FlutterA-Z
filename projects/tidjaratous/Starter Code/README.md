# TidjaratOus Card

Une application Flutter simple de type carte de profil, développée dans le cadre de la série YouTube **Flutter de A à Z – De Débutant à Développeur Pro**.

Ce projet s'inspire du projet pédagogique Mi Card et l'adapte à l'identité de TidjaratOus.

##  Objectif du projet

Apprendre les fondamentaux de Flutter en construisant une interface de carte de profil étape par étape.

Ce projet suit notre philosophie d'apprentissage :

**Comprendre → Construire → Accélérer avec l'IA**

## Notions abordées

- Différence entre Hot Reload et Hot Restart
- Utilisation de `Container`, `Column` et `Row`
- Utilisation de `CircleAvatar` et `Text`
- Intégration de polices personnalisées
- Utilisation des icônes Material et de `SizedBox`
- Gestion des couleurs et styles de base
- Utilisation de `Card` et `ListTile`
- Comparaison entre une interface développée manuellement et une interface générée avec l'aide de l'IA

## Prérequis

Avant de commencer, assure-toi d'avoir installé :

- Le SDK Flutter
- Le SDK Dart (inclus avec Flutter)
- Un éditeur de code tel que VS Code ou Android Studio
- Un appareil connecté ou un émulateur pour exécuter l'application

Pour vérifier ton installation de Flutter, exécute la commande suivante :

```bash
flutter doctor
```

## Installation et exécution

1. Clone ce dépôt GitHub ou télécharge-le sur ton ordinateur.
2. Accède au dossier du projet TidjaratOus Card.
3. Ouvre la version souhaitée : Starter Code ou Final Code.
4. Installe les dépendances.
5. Lance l'application.

```bash
flutter pub get
flutter run
```

**Important :** exécute ces commandes depuis le dossier contenant le fichier `pubspec.yaml` de la version choisie.

## Versions du projet

### Starter Code

Le code de départ utilisé dans le tutoriel.

Cette version permet de suivre les leçons et de construire progressivement l'interface en appliquant les notions présentées dans les vidéos.

### Final Code

La version finale du projet, disponible pour consulter le résultat, comparer son code avec celui du tutoriel et approfondir sa compréhension.
