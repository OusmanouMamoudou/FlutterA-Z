# 💎 I Am Rich

**I Am Rich** est le premier projet pratique de la série YouTube **Flutter de A à Z**.

L'objectif de ce projet est de découvrir la structure d'une application Flutter et de construire une première application simple, depuis la création du projet jusqu'à son installation sur un téléphone Android.

</p>

---

## 🎯 Ce que nous apprenons

À travers ce projet, nous découvrons notamment :

- `main()`
- `runApp()`
- `MaterialApp`
- `Scaffold`
- `AppBar`
- `Center`
- `Text`
- `Image`
- le **Widget Tree**
- les couleurs Material
- les assets locaux
- `pubspec.yaml`
- `Image.asset`
- la personnalisation de l'icône de l'application
- l'exécution de l'application sur un émulateur
- l'installation et le test sur un téléphone Android physique

---


## 🚀 Lancer le projet

### 1. Clonez le dépôt

```bash
git https://github.com/OusmanouMamoudou/FlutterA-Z/tree/master/i_am_rich
```

### 2. Accédez au code final de I Am Rich

```bash
cd FlutterA-Z/projects/i_am_rich
```

### 3. Installez les dépendances

```bash
flutter pub get
```

### 4. Lancez l'application

```bash
flutter run
```

---

## ⚙️ Prérequis

Avant de lancer le projet, assurez-vous d'avoir :

- Flutter installé ;
- VS Code ou Android Studio configuré ;
- un émulateur Android ou un téléphone physique prêt à être utilisé.

Les étapes de configuration sont expliquées dans les premières vidéos de la playlist **Flutter de A à Z**.
